## タスクの作成

1. [0000-template.md](./0000-template.md) をコピーして作成(番号は最新 + 1、`{4桁}-{ケバブケース}.md`)
2. 記入後、この README の一覧表に追加
3. 必要に応じて GitHub Issue を作成し相互リンク

## ステータス / 優先度の意味

- ステータス: **Backlog**(仕様未確定) / **Ready**(着手可能) / **In Progress** / **In Review** / **Done**
- 優先度: **Critical**(互換性・データ保全) / **High** / **Medium** / **Low**
